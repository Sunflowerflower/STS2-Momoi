## 1. 颜色规则

- 王小桃的代表色：**桃红色 `#D95C97`**。
- C# 里已对应：
  - `STS2_MomoiCharacter.MomoiPink`
  - `NameColor`
  - `EnergyLabelOutlineColor`
  - `STS2_MomoiCardPool.EnergyOutlineColor`
- 本地化里如果要**精确**指定这个颜色，用 BBCode：
  - `[color=#D95C97]王小桃[/color]`
  - 只说颜色名时：**桃红色**
- 内置 `[pink]` 也可以，但它是原版粉色（亡灵契约师偏紫粉），不如 `#D95C97` 准确。
- `{character}` 这类格式化占位符是否自动继承 `NameColor` 取决于具体 formatter；事件里如果要强调，**手写** `[color=#D95C97]王小桃[/color]` 最稳。

## 2. 先古之民（Ancient）对话

> 王小桃专属的 36 组对话已写入 `localization/{zhs,eng}/ancients.json`；实现细节见 `工作区/_docs/_王小桃先古对话.md`。

参考文件：

> **全量整理：`工作区/_docs/_先古之民对话整理.md`**（9 位先古/建筑师、287 条台词，按角色/对话组分类，含语气速记）

- 文本：`C:\Users\asus\Desktop\Slay the Spire 2\localization\zhs\ancients.json`（英文 `localization\eng\ancients.json`）
- 代码：`C:\Users\asus\Desktop\Slay the Spire 2\src\Core\Entities\Ancients\AncientDialogue*.cs`
- 结构：`AncientDialogueSet` / `AncientDialogue` / `AncientDialogueLine` / `AncientDialogueSpeaker`

常见 key 结构：

```text
<ANCIENT>.epithet
<ANCIENT>.talk.<CHARACTER>.0-0.ancient
<ANCIENT>.talk.<CHARACTER>.0-0.next
<ANCIENT>.talk.<CHARACTER>.0-1.char
<ANCIENT>.talk.<CHARACTER>.0-2.ancient
<ANCIENT>.talk.<CHARACTER>.1-0r.ancient
```

- `ancient` = 先古之民说的话。
- `char` = 角色回答；可用 `[i][font_size=22]...[/font_size][/i]` 做动作/拟声。
- `next` = 分支按钮文本（如「回应」「提问」「继续」）。
- `0-0r` 里的 `r` 表示重复/复访台词；**同一组所有行都要带 r**，否则 `AncientDialogue.PopulateLines` 会抛异常。
- `...{组号}-visit` 可覆盖访问序号（RitsuLib 非建筑师默认 0/1/4/7）；王小桃四组显式写 0/1/2/3。
- 颜色规范：红 `[red]` 给会痛的敌人/至亲，青 `[aqua]` 给被挂念之物，金 `[gold]` 只给人名；坦克斯用整句 `[b]`，特兹卡塔拉关键词用 `[jitter][b]`。

现有先古之民 ID（从本地化文件实测）：

`DARV`、`NEOW`、`NONUPEIPE`、`OROBAS`、`PAEL`、`TANX`、`TEZCATARA`、`THE_ARCHITECT`、`VAKUU`

例子（DARV，囤积者）：

```text
DARV.talk.ANY.0-0r.ancient = 来来，这里有些被遗忘的宝石，拿一块去吧！
DARV.talk.IRONCLAD.0-0.ancient = 啊，冒火的战士回来啦！\n我这儿有东西正适合你！
DARV.talk.DEFECT.0-1.char = [i][font_size=22]<3[/font_size][/i]
DARV.talk.DEFECT.0-0.next = 回应
```

给王小桃写先古之民台词的注意点：

1. 先古之民是**对角色说话**，不是旁白；保持原版短句、口语、略带古怪的语气。
2. 角色回答可用动作/拟声（`<3`、`<好奇的嘀嘀声>`），王小桃适合游戏/编程/编剧梗。
3. 涉及她的名字时：
   - `[color=#D95C97]王小桃[/color]`
   - 或直接使用「你」，避免每句都重复名字。
4. 自定义角色要新增 `<ANCIENT>.talk.<你的 CharacterId>.…`；具体 ID 用 `Character.Id.Entry`（本项目本地化键是 `STS2_MOMOI_CHARACTER_STS2_MOMOI_CHARACTER`），接入前先用日志确认 lookup 的 ID。

## 3. 问号房 / 事件参考：色彩哲学家

参考：

- 代码：`C:\Users\asus\Desktop\Slay the Spire 2\src\Core\Models\Events\ColorfulPhilosophers.cs`
- 中文文本：`localization\zhs\events.json` 的 `COLORFUL_PHILOSOPHERS.*`
- 图片：`images\events\colorful_philosophers.png`
- VFX：`scenes\vfx\events\colorful_philosophers_vfx.tscn`

原版事件结构：

```text
COLORFUL_PHILOSOPHERS.title = 色彩哲学家
COLORFUL_PHILOSOPHERS.pages.INITIAL.description = ...
COLORFUL_PHILOSOPHERS.pages.INITIAL.options.<POOL>.title = 红色/蓝色/绿色/橙色/粉色
COLORFUL_PHILOSOPHERS.pages.INITIAL.options.<POOL>.description = 获得[blue]{Cards}[/blue]张…的卡牌。
```

- 原版 `CardPoolColorOrder` 只列了 5 个原版卡池：
  `NECROBINDER`（粉色）、`IRONCLAD`（红色）、`REGENT`（橙色）、`SILENT`（绿色）、`DEFECT`（蓝色）。
- 选项 key 的后缀是 `cardPool.EnergyColorName.ToUpperInvariant()`；本项目卡池是 `STS2_MOMOI`，所以如果要加入：
  - `COLORFUL_PHILOSOPHERS.pages.INITIAL.options.STS2_MOMOI.title` = **桃红色**
  - `COLORFUL_PHILOSOPHERS.pages.INITIAL.options.STS2_MOMOI.description` = `获得[blue]{Cards}[/blue]张王小桃的卡牌。`
- **仅加本地化还不够**：`ColorfulPhilosophers.GenerateInitialOptions()` 遍历的是写死的 `CardPoolColorOrder`，需要：
  1. 用 Harmony 后置补丁把 `STS2_MomoiCardPool` 加进去；或
  2. 复制/重写该事件选项逻辑。
- 事件文本风格：`[jitter][red]…[/red][/jitter]`、`[gold]…[/gold]`、`[blue]{Cards}[/blue]`；颜色名本身是纯文本（`桃红色`），不要给 `title` 加 markup（选项标题是普通 Label）。

## 4. 其他事件文本

- 事件通用文件：`localization\zhs\events.json` / `localization\eng\events.json`
- 常见占位符：`{character}`、`{Cards}`、`{event}`、`{possessiveAdjective}`
- 失败行常用 `{character}` 开头，例如：
  `ABYSSAL_BATHS.loss = "{character}溺毙于[gold]{event}[/gold]之中。"`
- 如果 `{character}` 没有按 `NameColor` 上色，就在事件文本里显式写：
  `[color=#D95C97]王小桃[/color]溺毙于[gold]{event}[/gold]之中。`
- 事件选项/描述里的数值用 `[blue]`，关键词用 `[gold]`；不要手写「消耗/保留」等徽章文本（由 `CanonicalKeywords` 自动追加）。

## 6. 海玻璃 / 设置开关

### 海玻璃
原版 `SeaGlass.Title` 在 `CharacterId != null` 时读：

```text
SEA_GLASS.<Character.Id.Entry>.title
```

王小桃已加：

```text
SEA_GLASS.STS2_MOMOI_CHARACTER_STS2_MOMOI_CHARACTER.title = 给木玻璃
（英文：Game Glass）
```

奥罗巴斯的 `SeaGlassOptions` 会遍历 `ModelDb.AllCharacters`，本角色自动进入；设置关闭时由 `MomoiSeaGlassPoolPatch` 过滤。

### 设置页
`STS2 MomoiCode/Settings/MomoiSettings.cs` 注册了 RitsuLib 设置页：

- 「色彩哲学家出现该角色卡池」
- 「海玻璃出现该角色」
- 「音量」栏：总音量 / 音乐音量 / 语音音量 / 音效音量四个 0–100% 滑块

数据存在 Global `settings.json`。以后加更多选项：

1. 在 `MomoiModSettings` 加字段（例如 `bool BuffMomoiCards`、`bool OnlyMomoiNewEvents`）；
2. 加 `ModSettingsValueBinding<MomoiModSettings,bool>`；
3. 在 `RegisterModSettings` 页面 `.AddToggle(...)`；
4. 在对应逻辑里 `.Read()`；需要时 `.Save()`。
