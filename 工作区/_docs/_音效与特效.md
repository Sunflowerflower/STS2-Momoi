# 王小桃音效与战斗特效

> 2026-10-25 更新。音效走 RitsuLib `VirtualFmodEventRegistry`；m4a 用 ffmpeg 转为 ogg。

## 1. 音量设置

设置页「王小桃 → 音量」六个滑块（死亡为 0–700%，其余 0–100%）：

| 设置 | 作用 |
|---|---|
| 总音量 | 乘到所有王小桃音效/音乐上 |
| 音乐音量 | 控制残血 BGM 与选人界面 BGM |
| 语音音量 | BA启动、创作痛苦语音、小游戏生成、胜利剧本、当心误射、虚拟女仆武器 |
| 音效音量 | 基础枪声、创作痛苦冲击音；后续战斗音效放这里 |
| 受击语音音量 | 受伤音效单独控制，默认 100% |
| 死亡语音音量 | 死亡音效单独控制，默认 **500%**，最高 **700%**（避免被受击/其他语音淹没） |

实现：`Audio/MomoiAudio.cs`，每个事件播放前用 `Master × 分类` 更新注册音量；残血 BGM / 选人 BGM 用 `MusicGain`（或 `MusicVolumeDb`）写 `AudioStreamPlayer.VolumeDb`。

## 2. 选人界面 BGM

| 背景 | 曲目 | 文件 | 绑定 |
|---|---|---|---|
| 白天 `select_bg_1` | Pixel Time | `STS2_Momoi/audio/select_bgm_day.ogg` | `STS2_Momoi_character_select_bg_1.tscn` 的 `SelectBgm` |
| 夜间 `select_bg_2` | Operation☆DOTABATA | `STS2_Momoi/audio/select_bgm_night.ogg` | `STS2_Momoi_character_select_bg_2.tscn` 的 `SelectBgm` |

- 背景场景内的 `AudioStreamPlayer` 自动播放、OGG 导入 `loop=true`；背景被移除时节点一起释放。
- `Patches/MomoiSelectBgmPatch.cs` 每帧把 `MomoiAudio.MusicVolumeDb`（总音量 × 音乐音量）写到组 `momoi_select_bgm` 的播放器上；选人界面缓存隐藏时暂停，显示时恢复。
- 两首曲子绑定各自背景；`CustomCharacterSelectSfx` / `CustomCharacterTransitionSfx` 返回 null，不再回退铁甲战士音效。

| 用途 | 事件 | 分类 |
|---|---|---|
| 受伤 | `event:/STS2_Momoi/sfx/hurt` | 语音 |
| BA启动！ | `event:/STS2_Momoi/sfx/ba_boot` | 语音 |
| 创作的痛苦！语音 | `event:/STS2_Momoi/sfx/creative_pain` | 语音 |
| 创作的痛苦！冲击 | `event:/STS2_Momoi/sfx/creative_pain_impact` | 音效 |
| 小游戏牌生成 | `event:/STS2_Momoi/sfx/minigame_generated` | 语音 |
| 胜利的剧本 | `event:/STS2_Momoi/sfx/winning_script` | 语音 |
| 基础枪声 | `event:/STS2_Momoi/sfx/gunshot` | 音效 |
| 死亡 | `event:/STS2_Momoi/sfx/death_voice` | 死亡独立音量 |
| 当心误射！ | `event:/STS2_Momoi/sfx/watch_out_voice` | 语音 |
| 虚拟女仆武器 | `event:/STS2_Momoi/sfx/maid_weapon_voice` | 语音 |
| 免死复活 | `event:/STS2_Momoi/sfx/revive` | 语音 |

- 受伤：`MomoiLowHpController` 订阅 `CurrentHpChanged`，120ms 节流；不依赖遗物。
- 小游戏生成：起始遗物/满溢灵感的 `AfterCardGeneratedForCombat`；`CanBeTemporarilyAdded` 排除 fullgame 游戏牌。
- 免死：`MomoiReviveSfxPatch` 挂 `Hook.AfterPreventingDeath`，覆盖瓶中精灵/蜥蜴尾巴/我复活啦！；用直通 AudioStreamPlayer，避免战斗 ending 静默。
- 死亡语音：订阅 `CreatureDiedEvent`，在 `WasRemovalPrevented == false` 且 `LocalContext.IsMe` 时直通播放；覆盖战斗死亡、事件死亡、主动放弃；使用独立「死亡语音音量」，默认 500%，最高 700%。旧版 180/200 的设置会一次性迁移到 500%。
- 胜利剧本：`FlashSfx` + `Flash()`，播放前刷新语音音量。

## 5. 多段攻击动画

- 攻击牌在 `BeforeCardPlayed` 只登记本次 `attack1/2/3`，不主动播放；
  AttackCommand 每段伤害发标准 `Attack`，`MomoiStateMachineCueSuppressPatch` 把它改写成登记的动画。
- 因此除 **100连抽！** 外，多段攻击每段都会播放一次攻击动画；100连抽仍只播一次（占位，后续换新动画）。
- 创作痛苦拆成 3 条单段 AttackCommand：第 1 段无等待，第 2/3 段前各 `Cmd.CustomScaledWait(0.5f, 0.5f)`。
- 创作痛苦现在每段伤害前都会播攻击动画，不再是一次动作结算 3 段。
