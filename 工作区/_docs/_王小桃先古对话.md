# 王小桃专属先古之民对话（实现说明）

> 2026-10-24。台词设计由用户提供；本文件记录实现细节，完整文本以
> `STS2 Momoi/STS2_Momoi/localization/{zhs,eng}/ancients.json` 为准。
> 生成脚本：`工作区/_scripts/_build_momoi_ancient_dialogues.py`。

## 1. 规模

- **9 位**先古/建筑师：涅奥、达弗、诺奴佩普、欧洛巴斯、佩尔、坦克斯、特兹卡塔拉、瓦库、建筑师。
- 每位 **4 组**对话 = **36 组**。
- 每个语言 **166** 个 localization 键（含对话、next、visit、格式标签）。
- 角色 ID：`STS2_MOMOI_CHARACTER_STS2_MOMOI_CHARACTER`。

## 2. 四组都进入重复池

原版规则：访问次数精确匹配某组 `VisitIndex` 时优先返回该组；没有精确匹配时才从
`IsRepeating` 池抽取。Neow 的存档访问数很高（测试档 169 次），如果只有组 0 可重复，
后面只会一直看到组 0。

本模组：

1. **四组的每一行** key 都带 `r`（`AncientDialogue.PopulateLines` 要求同一组所有行一致）：
   ```text
   NEOW.talk.STS2_MOMOI_CHARACTER_STS2_MOMOI_CHARACTER.0-0r.char
   NEOW.talk.STS2_MOMOI_CHARACTER_STS2_MOMOI_CHARACTER.1-0r.char
   NEOW.talk.STS2_MOMOI_CHARACTER_STS2_MOMOI_CHARACTER.2-0r.char
   NEOW.talk.STS2_MOMOI_CHARACTER_STS2_MOMOI_CHARACTER.3-0r.char
   ```
2. 写 `...0-visit` ~ `...3-visit`，覆盖 RitsuLib 非建筑师的默认访问映射（默认 0/1/4/7），
   让四组分别落在第 **0/1/2/3** 次访问。
3. 结果：组 0/1/2/3 先分别在第 0/1/2/3 次访问优先出现；**第 4 次及以后四组都在重复池中随机**。
   这样高访问存档不会永远只看到组 0。

## 3. 文字特效

| 先古 | 规则 |
|---|---|
| 涅奥 | ancient 台词全部 `[sine]...[/sine]` 低语 |
| 坦克斯 | ancient 台词**整句** `[b]...[/b]`；组 3 旁白 `[i][font_size=22]小桃与坦克斯战斗了。[/font_size][/i]` |
| 特兹卡塔拉 | 关键词 `战斗` 用 `[jitter][b]战斗[/b][/jitter]`；原版关键词未出现在文本中时不硬加 |
| 瓦库 | 组 2 `[aqua]伙伴[/aqua]与[aqua]勇气[/aqua]`；组 3 旁白 `[i][font_size=22]瓦库大笑起来。[/font_size][/i]` |
| 其他 | 不加颜色；红色只给敌人/至亲，青色只给被挂念之物，金色只给人名 |

## 4. 校验

`_verify_batch32.py` 检查：

- zhs/eng 各 166 键；
- 所有对话行都带 r（含组 0-3）；
- 32 个 `-visit` 键；
- 坦克斯整句加粗 + 战斗旁白斜体；
- 特兹卡塔拉 `[jitter][b]战斗`；
- 瓦库 `[aqua]伙伴`。

构建：DLL **481,280 B** / PCK **128,107,776 B** / 1037 条目 / 24 补丁；
23 套 **1043 条全绿**。
