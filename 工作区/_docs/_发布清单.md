## 1. 现在就能发的：本地 mod 压缩包

**产物**：`工作区\发布包\STS2_Momoi_v1.0.4.zip`（约 125 MB，顶层就是 `STS2_Momoi/`）

重新打包（改完代码、`dotnet build` 之后跑一次）：

```bash
PY="C:\Users\asus\AppData\Local\Python\pythoncore-3.14-64\python.exe"
"$PY" 工作区/_scripts/_make_release_zip.py
```

脚本会先校验、再打包：

1. `mods\STS2_Momoi\` 里 `STS2_Momoi.dll` / `STS2_Momoi.pck` / `STS2_Momoi.json` **三个文件都在，且文件名与清单 `id` 完全一致**；
2. 清单 `has_dll` / `has_pck` 都是 true，`dependencies` 里有 `{ "id": "STS2-RitsuLib", "min_version": "0.6.7" }` —— **键名必须是 `min_version`**，写成 `version` 会被游戏静默忽略（等于不校验版本）；`min_version` 是手动兼容底线，构建时 `ValidateManifestDependencies` 只校验不改写；
3. zip 的**顶层就是 `STS2_Momoi/`**（另外塞了一份 `README.txt` 安装说明，不进部署目录）。

玩家侧：解压到 `Slay the Spire 2/mods/` → 启动游戏 → 首次运行弹「启用模组」提示 → 允许即可。

> ⚠ **本地版 vs 工坊版**：两者 `id` 相同会互相抢占 —— 游戏会把版本号更低的那个禁用掉。
> 以后同时上工坊时，让两边版本号一致，或者临时移走 `mods\STS2_Momoi\`。
> ⚠ **联机**：两端必须用同一份文件。

## 3. 更新检查（可选，暂未启用）

把下面这份 JSON 放到任意 HTTPS 地址，然后在 `Entry` 里注册即可（现在**没有注册**，等你有固定下载页再加）：

```json
{
  "schema": 1,
  "latest_version": "1.0.4",
  "title": "游戏王小桃 1.0.4",
  "message": "更新内容：……",
  "release_page_url": "https://steamcommunity.com/sharedfiles/filedetails/?id=3830602273"
}
```
